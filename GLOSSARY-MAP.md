# Glossary Map

Terms shared by every package live in the root [GLOSSARY.md](./GLOSSARY.md). Each package of `lib/` can own its glossary. A context is listed here once its `GLOSSARY.md` exists; system-wide decisions live in `docs/adr/`, package-scoped ones in `lib/<Package>/docs/adr/`.

## Contexts

- [Roadiz](./GLOSSARY.md): terms shared by every package (extension point, breaking change, deprecation). Decisions in [`docs/adr/`](./docs/adr/)
- [Rozier](./lib/Rozier/GLOSSARY.md): the backoffice UI and its redesign. Decisions in [`lib/Rozier/docs/adr/`](./lib/Rozier/docs/adr/)
